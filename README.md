# 捷途密码箱

专为捷途车主设计的**车机&ADB动态口令计算器**，支持多种车型和版本，基于当前时间自动生成有效口令。


## 🚗 功能说明
1. **工程模式口令**：用于进入工程模式（应用中心→蓝牙电话，输入上方口令）。  
2. **ADB权限口令**：用于工程模式加密设置（进入工程模式→加密设置，输入上方口令）。  
3. **自动更新**：口令根据算法类型自动更新（每小时/每天/固定口令）。  
4. **多车型支持**：支持捷途旅行者、自由者、大圣等多种车型。

## 💻 使用方法
1. 在线使用：访问 [pw.qianxian.tech](https://pw.qianxian.tech/) 直接使用
2. 本地使用：
   ```bash
   # 1) 复制接口配置模板（只需接口地址，前端不再需要任何密钥）
   cp config.example.js config.local.js

   # 2) 起一个本地静态服务器（页面用了 ES Module，直接双击 index.html 会被浏览器 CORS 拦截）
   python3 -m http.server 8000
   # 浏览器打开 http://127.0.0.1:8000/index.html
   ```
   `config.local.js` 已在 `.gitignore` 中，不会被提交。
3. 后台配置（验证密码开关）：本地同样起服务后访问 `/admin.html`，需填写服务端的 `ADMIN_TOKEN`；
   该页面不随站点发布。


## ⚠️ 注意事项
- 动态口令基于**当前时间**计算，若设备时间不准会导致口令错误，请确保系统时间正确。  
- 不同车型和版本使用不同的算法，请选择正确的车型和版本。  
- 底部说明中的车型适配以官方信息为准，如有变动请自行核对。  


## 🔐 接口鉴权

前端不再持有任何密钥，改用服务端签发的短期票据：

1. 前端向 `POST /api/ticket` 申请一张只读票据（HMAC-SHA256 签名，默认 10 分钟）；
2. 后续请求放进 `X-Access-Ticket` 头，服务端验签后放行；票据过期会自动换新重试一次；
3. 后台 `/api/admin/*` 不认只读票据，需用 `ADMIN_TOKEN` 换 admin 票据，未配置时默认全部关闭。

服务端环境变量（见 `deploy/.env.example`）：

| 变量 | 说明 |
|---|---|
| `SIGNING_SECRET` | 必填，票据签名密钥（`openssl rand -hex 32`） |
| `ADMIN_TOKEN` | 选填，后台口令；不设置则 `/api/admin/*` 返回 403 |
| `ALLOWED_ORIGINS` | 来源白名单，逗号分隔；留空则不校验来源 |
| `TICKET_TTL_MS` | 只读票据有效期，默认 600000（10 分钟） |
| `TICKET_BIND_IP` | 票据是否绑定客户端 IP，默认 0（关闭，避免切换网络被误伤） |

> 来源校验只对真实浏览器有效，`curl` 可以伪造 `Origin`。它只是抬高批量调用的门槛，
> 真正抗刷仍依赖限流；如需更强保障，可在 `/api/ticket` 前接入 Cloudflare Turnstile 等人机校验。
